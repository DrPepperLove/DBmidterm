已实现的功能
```
┌───────────────────────┬────────────────────────────────────────────────┐
│         功能          │                      说明                      │
├───────────────────────┼────────────────────────────────────────────────┤
│ 用户注册/登录         │ 区分 reader/admin 角色，SHA-256 密码哈希       │
├───────────────────────┼────────────────────────────────────────────────┤
│ 图书浏览搜索          │ 按分类筛选 + 关键词模糊搜索 (书名/作者)        │
├───────────────────────┼────────────────────────────────────────────────┤
│ 图书详情              │ 馆藏副本、评分、评论展示                       │
├───────────────────────┼────────────────────────────────────────────────┤
│ 借阅 (sp_borrow_book) │ 事务锁定行 → 检查副本 → 扣减库存 → 插记录      │
├───────────────────────┼────────────────────────────────────────────────┤
│ 归还 (sp_return_book) │ 更新记录 → 恢复副本 → 触发预约检查             │
├───────────────────────┼────────────────────────────────────────────────┤
│ 预约                  │ 副本为0时可预约，归还后自动通知                │
├───────────────────────┼────────────────────────────────────────────────┤
│ 评论                  │ 仅借阅并归还后可评，一人一书一条 (UNIQUE 约束) │
├───────────────────────┼────────────────────────────────────────────────┤
│ 热门 Top 5            │ 基于借阅次数统计                               │
├───────────────────────┼────────────────────────────────────────────────┤
│ 管理员功能            │ 图书/分类/用户/借阅 CRUD，逾期查询，强制归还   │
└───────────────────────┴────────────────────────────────────────────────┘
```
数据库对象 (完全对应 doc.md 设计)

- 6 张表: user, category, book, borrow_record, review, reservation — 均满足 3NF
- 2 个视图: view_borrow_details, view_book_rating
- 6 个索引: 借阅用户、借阅书状态、书名/作者搜索、评论聚合
- 存储过程: sp_borrow_book / sp_return_book 在 Python 中以事务实现
- 触发器: trg_after_return / trg_prevent_duplicate_review 在 Python 中实现
